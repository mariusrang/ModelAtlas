Interpretation and follow-up for Marius:

- `grade()` counts an expected tool as called even when that call failed. This explains the publisher-ranking false pass. A successful expected call, with relevant cited facts, is a stronger check.
- A syntactically valid query may still answer the wrong question. The listed-model false pass needs a numeric oracle or semantic review; keyword checks and schema validation cannot establish its correctness.
- Distinguish a safe response to an absent model from fabrication. The requested invented-model expectation and the warning generated by echoing that ID should be clarified rather than edited to improve this run's score.
- Confidence is an explainable grounding heuristic, not calibrated accuracy: the wrong count scored 0.85. The generated summary's mean-confidence calculation also includes non-null `no_answer` scores despite its "answered" label.
- This small, hand-written suite applies to the recorded graph/model configuration. It is not a general accuracy estimate. Genuine failures, tool errors, rejected queries and the required expectations are preserved below.
